Implemented interpretable deep learning models using the **Prototypical Part Network (ProtoPNet)** architecture. Unlike traditional black-box CNNs, ProtoPNet provides:

- **Case-based reasoning**: Explanations grounded in learned visual prototypes
- **Visual interpretability**: Each prediction is justified by similarity to prototype image patches
- **Multiple backbones**: Implemented with both ResNet-20 and VGG-16 architectures

This project explores the tradeoff between accuracy and interpretability in deep learning, providing insights into building trustworthy AI systems for high-stakes applications like medical imaging and industrial inspection.
